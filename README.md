# 🚀 Personal Study & Code Reference Hub

A lightweight, highly responsive, and dark-themed web application designed to organize programming notes, topics, and code snippets in one place. No complex frameworks or heavy setups required—just pure HTML, CSS, and JavaScript!

---

## ✨ Features

- **🌙 Sleek Dark Theme:** Modern, eye-friendly design optimized for developers and long study sessions.
- **🔍 Live Search Bar:** Instantly filter and find topics by their titles or notes in real-time.
- **🔢 Quick ID Index Panel:** A dedicated sidebar displaying all unique topic IDs for lightning-fast navigation.
- **💻 Code Editor & Viewer:** 
  - **Edit Mode:** Write and update code snippets seamlessly.
  - **Read-Only Mode:** Clean, syntax-highlighted code blocks powered by [Prism.js](https://prismjs.com/).
- **💾 Local Storage Persistence:** All your topics, notes, and code snippets are automatically saved directly in your browser's `localStorage`.
- **⚡ Zero Dependencies:** Runs instantly right out of the box.

---

## 🛠️ Built With

- **HTML5** & **CSS3** (Custom Properties / Variables)
- **Vanilla JavaScript (ES6+)**
- **FontAwesome** (Icons)
- **Google Fonts (Cairo)**
- **Prism.js** (Syntax Highlighting)
